# Pathfinder
 Create an app that starts out with info about you, hobbies, interests, future aspects, then create a personality test, then give job recommendation, and based on the selected job, create a day by day schedule to show improvement and dedication. The app will create a daily schedule for the student based on their selected job, and this can be modified by the student. Ex: data scientist, you need to be good at math and statistics, you would make a path for the high school course, by enrolling in math competitions, olympiads etc, and improve your stamina day by day. The app will give modified practice based on the users accuracy and completion. Input AI uses a tracker so students cannot be dishonest. The app can give prizes or awards for completing or doing well on something.
